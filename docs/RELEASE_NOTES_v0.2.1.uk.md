## Новий інсталятор

- Виправляє помилку **1605**, пов’язану зі змішуванням системної реєстрації розкладки й інсталяції MSI для поточного облікового запису.
- Під час видалення вибирається справді зареєстрований продукт після перевірки його MSI в кеші, назви й DLL, без припущення про збіг із завантаженим пакетом.
- Наявні інсталяції для користувача видаляються з облікового запису власника. Інсталяції для комп’ютера потребують дозволу адміністратора.
- Нові інсталяції реєструються для всього комп’ютера; розкладка за замовчуванням залишається окремим налаштуванням кожного облікового запису.
- Відсутні, неоднозначні чи неперевірювані продукти виявляються до відновлення налаштування за замовчуванням. Файли розкладок і записи реєстру не видаляються вручну.
- Вікно й діалоги тепер показують **v0.2.1**. Властивості файлу містять ту саму версію. Видалення системної розкладки може вплинути на інші облікові записи.

## Надійність і документація

- Нові інсталяції MSI явно використовують `ALLUSERS=1`. Видалення інсталяції для користувача не перезапускається від імені іншого адміністратора.
- Докладні журнали `/L*V` і дані про продукт та контекст зберігаються локально в `%LOCALAPPDATA%\AngleQuotes\logs`. Вони не надсилаються автоматично й можуть містити ідентифікатори облікових записів і шляхи.
- Код успіху `0` перевіряється за списком MSI до підтвердження завершення. Код потреби перезавантаження `3010` зберігається. Версія має єдине джерело.

## Сумісність і попередження

DLL розкладок, пакети MSI, призначення символів і тренувальні тексти не змінилися порівняно з v0.2.0. Зберігається підтримка Windows 10/11 на x86/x64; ARM64 не включено. Для появи або правильної роботи розкладки Windows може вимагати вихід із системи чи перезавантаження.

SmartScreen: попередження «Система Windows захистила ваш комп’ютер» із написом «Невідомий видавець» спостерігалося під час запуску setup.exe, завантаженого з GitHub, як у v0.1.0, так і у v0.2.0. Інсталятори досі не мають цифрового підпису. Якщо ви перевірили джерело файлу й вирішили продовжити, виберіть «Докладніше», а потім «Виконати в будь-якому разі», якщо Windows пропонує цей варіант. Вимикати SmartScreen або Microsoft Defender не потрібно.

## Перевірки

- 26 ізольованих перевірок ідентичності й контексту MSI та наявні 35 перевірок налаштувань проходять у Windows PowerShell 5.1 для 32 і 64 біт. Налаштування Windows та операції MSI імітуються.
- 238 перевірок метаданих, архітектур, назв, вбудованих ресурсів і версій охоплюють усі 17 розкладок. DLL і пакети MSI не змінилися.
- Перевіряються хеші 18 ZIP-архівів, вміст папок, копії документації, локальні посилання й кодування. Перевірки без запису охоплюють нативне виявлення MSI та справжній запуск.
- Я успішно перевірив Spanish (Spain) у новому обліковому записі: встановлення, увімкнення/вимкнення за замовчуванням, збереження після виходу із системи чи перезавантаження та видалення. Спочатку я видалив стару інсталяцію для користувача. Я не перевіряв вручну інші 16 розкладок і всі конфігурації Windows; переклади не пройшли незалежної мовної перевірки. Остаточна збірка додає відображення версії до перевіреної логіки.

Якщо стара інсталяція належить іншому обліковому запису, спочатку видаліть її з початкового запису, а потім установіть цю версію з потрібного. Створення нового облікового запису чи запуск нового інсталятора не переносить наявну реєстрацію MSI для користувача. Я успішно виконав цей перехід, а потім повторив повну перевірку в новому обліковому записі.

## Завантаження

Виберіть `ANGLE_QUOTES_NATIVE_WINDOWS.zip` для всіх розкладок або окремий ZIP для своєї. Повністю розпакуйте ZIP і зберігайте файли разом. У `SHA256SUMS.txt` наведено хеші SHA256 усіх 18 доступних ZIP-архівів.

Архіви **Source code** ZIP/TAR.GZ на GitHub створюються окремо й не є пакетами встановлення.
