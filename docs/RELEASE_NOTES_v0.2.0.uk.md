## Новий інсталятор

- Усі 17 розкладок тепер мають вікно встановлення з необов’язковим прапорцем **Використовувати за замовчуванням для мого облікового запису**. Установіть прапорець і виконайте встановлення або застосуйте зміну, щоб зберегти метод введення за замовчуванням у Windows.
- Знову відкрийте `setup.exe`, зніміть прапорець і натисніть **Застосувати**, щоб відновити попереднє налаштування, залишивши розкладку встановленою. Якщо попередня розкладка недоступна, інсталятор запропонує вибрати інший доступний метод введення.
- Прапорець відображає поточне налаштування Windows. Інші мови й розкладки зберігаються; повторне ввімкнення не замінює початкові дані відновлення цією самою розкладкою.
- **Видалити** спочатку відновлює попередній метод введення за замовчуванням, якщо потрібно, а потім видаляє розкладку. Пряме видалення через MSI або програми Windows пропускає цей додатковий крок відновлення.
- Інтерфейс відповідає мові Windows: іспанській, англійській, французькій, німецькій, італійській, португальській, норвезькій букмол, данській, російській, українській і білоруській. За відсутності перекладу використовується англійська.
- Відкривайте `setup.exe` звичайним способом, без **Запуску від імені адміністратора**. Підвищення прав потрібне лише для операцій MSI; налаштування введення стосуються облікового запису, який відкрив інсталятор. Фонова програма й заплановане завдання не встановлюються.

## Надійність і документація

- Інсталятор уникає зайвих запитів налаштувань під час запуску. Якщо запит Windows про метод введення за замовчуванням спричиняє загальний виняток, він читає збережене налаштування без запису. Помилки доступу й некоректні значення залишаються помилками.
- Помилки налаштування показують команду й місце у скрипті та зберігають локальний діагностичний файл у `%LOCALAPPDATA%\AngleQuotes\logs`. Журнали не надсилаються автоматично.
- Інструкції зі встановлення, відновлення й видалення оновлено всіма 11 мовами README та в папках 17 розкладок. Додано вихідний код збирання, переклади й ізольовані тести налаштувань.

## Сумісність і попередження

DLL розкладок, пакети MSI, призначення символів і тренувальні тексти не змінилися порівняно з v0.1.0. Зберігається підтримка Windows 10/11 на x86/x64; ARM64 не включено. Для появи або правильної роботи розкладки Windows може вимагати вихід із системи чи перезавантаження.

Інсталятори й далі не мають цифрового підпису. Попередження SmartScreen **Система Windows захистила ваш комп’ютер** спостерігалося у v0.1.0; під час успішної перевірки кандидата v0.2.0 про нього не повідомлялося. Непідписаний інсталятор v0.2.0 може й надалі показувати попередження. Ця версія не видаляє і не вимикає захист SmartScreen.

## Перевірки

- 35 ізольованих перевірок налаштувань проходять у Windows PowerShell 5.1 у 32- та 64-бітному виконанні з імітацією налаштувань Windows і записів реєстру.
- Проходять 204 перевірки метаданих інсталяторів, архітектур, відображуваних назв і вбудованих ресурсів. Звіти таблиць символів охоплюють усі 17 розкладок: по 11 016 порівнянь символів для x86, x64 і WOW64 та перевірки мертвих клавіш.
- Аудити пакетів перевіряють хеші 18 ZIP-архівів, вміст окремих папок, копії README, локальні посилання й кодування. Реальний шлях запуску також перевірено без запису в 32- та 64-бітній PowerShell.
- Користувач повідомляє про успішну загальну ручну перевірку виправленого кандидата **Spanish (Spain) - Angle Quotes** у Windows Home x64, зазначена версія 26H2, збірка 26300.9818. Окремі випадки не записувалися. Це не підтверджує ручну перевірку інших 16 розкладок або всіх підтримуваних версій Windows. Нові переклади не пройшли незалежної мовної перевірки.

Додаткова перевірка сумісності зі слів користувача: за вже встановленої розкладки v0.1.0 інсталятор v0.2.0 правильно розпізнав наявну інсталяцію та дозволив вибрати її за замовчуванням. Це підтверджує цей сценарій на перевіреному комп’ютері, але не повне видалення й повторне встановлення або охоплення всіх розкладок.

## Завантаження

Виберіть `ANGLE_QUOTES_NATIVE_WINDOWS.zip` для всіх розкладок або окремий ZIP для своєї. Повністю розпакуйте ZIP і зберігайте файли разом. У `SHA256SUMS.txt` наведено хеші SHA256 усіх 18 доступних ZIP-архівів.

Архіви **Source code** ZIP/TAR.GZ на GitHub створюються окремо й не є пакетами встановлення.
