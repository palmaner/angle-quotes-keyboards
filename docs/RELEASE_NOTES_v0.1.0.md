# v0.1.0 — First public release

I created these native Windows layouts to make «angle quotes» easy to type with AltGr, without AutoHotkey or a background app.

## Downloads

- **ANGLE_QUOTES_NATIVE_WINDOWS.zip**: all 17 layouts, with individual instructions.
- **Individual layout ZIPs**: download only the keyboard you want.
- **SHA256SUMS.txt**: checksums for the downloadable ZIPs.

I have also included AI-generated practice collections with angle quotes in context. Short, medium and long refer to the length of **each paragraph**, not the file or the story: usually around 10–25, 25–50 and 80–120 words respectively. Blank lines separate paragraphs. These texts may contain errors and are intended only for practice, including Monkeytype's custom text mode.

Choose by your existing keyboard layout, rather than nationality. The English (United States) and English (United Kingdom) variants are experimental and intended for trying angle quotes.

## Install

Extract the whole ZIP, open your layout's folder and run **setup.exe**. Approve the administrator prompt, then select the layout ending in **“- Angle Quotes”** with **Windows+Space**.

**The installer can behave inconsistently. Signing out and back in may be required before the keyboard appears or works correctly.** The packages target Windows x86/x64; ARM64 is not included. The installers are unsigned.

## Character changes and testing

Read the included local README for the exact mappings and displaced symbols. The Swiss variants currently replace ¢ and ¦ without assigning new shortcuts to them.

I have tried five of the original layouts on my laptop. Automated checks cover all 17 layouts across x86, x64 and WOW64, including character tables, accents and Windows display names. The two English variants have not yet been manually tested.
