## Новый установщик

- Все 17 раскладок теперь включают окно установки с необязательным флажком **Использовать по умолчанию для моей учётной записи**. Установите флажок и выполните установку или примените изменение, чтобы сохранить метод ввода по умолчанию в Windows.
- Снова откройте `setup.exe`, снимите флажок и нажмите **Применить**, чтобы восстановить прежнюю настройку, оставив раскладку установленной. Если прежняя раскладка недоступна, установщик предложит выбрать другой доступный метод ввода.
- Флажок отражает текущую настройку Windows. Другие языки и раскладки сохраняются; повторное включение не заменяет исходные данные восстановления этой же раскладкой.
- **Удалить** сначала восстанавливает прежний метод ввода по умолчанию, если необходимо, а затем удаляет раскладку. Прямое удаление через MSI или приложения Windows пропускает этот дополнительный шаг восстановления.
- Интерфейс следует языку Windows: испанскому, английскому, французскому, немецкому, итальянскому, португальскому, норвежскому букмолу, датскому, русскому, украинскому и белорусскому. При отсутствии перевода используется английский.
- Открывайте `setup.exe` обычным способом, без **Запуска от имени администратора**. Повышение прав запрашивается только для операций MSI; настройки ввода применяются к учётной записи, открывшей установщик. Фоновое приложение и запланированная задача не устанавливаются.

## Надёжность и документация

- Установщик избегает ненужных запросов настроек при запуске. При обычном исключении из запроса Windows о методе ввода по умолчанию он читает сохранённую настройку без записи. Ошибки доступа и некорректные значения по-прежнему считаются ошибками.
- Ошибки настройки показывают команду и место в скрипте и сохраняют локальный файл диагностики в `%LOCALAPPDATA%\AngleQuotes\logs`. Журналы не отправляются автоматически.
- Инструкции по установке, восстановлению и удалению обновлены на всех 11 языках README и в папках 17 раскладок. Включены исходники сборки, переводы и изолированные тесты настроек.

## Совместимость и предупреждения

DLL раскладок, пакеты MSI, назначения символов и тренировочные тексты не изменились по сравнению с v0.1.0. Сохраняется поддержка Windows 10/11 на x86/x64; ARM64 не включена. Для появления или правильной работы раскладки Windows может потребовать выход из системы или перезагрузку.

Установщики по-прежнему не имеют цифровой подписи. Предупреждение SmartScreen **Система Windows защитила ваш компьютер** наблюдалось в v0.1.0; при успешной проверке кандидата v0.2.0 о нём не сообщалось. Неподписанный установщик v0.2.0 всё ещё может вызвать предупреждение. Эта версия не удаляет и не отключает защиту SmartScreen.

## Проверки

- 35 изолированных проверок настроек проходят в Windows PowerShell 5.1 как 32-, так и 64-разрядной версии с имитацией настроек Windows и записей реестра.
- Проходят 204 проверки метаданных установщиков, архитектур, отображаемых имён и встроенных ресурсов. Отчёты таблиц символов охватывают все 17 раскладок: по 11 016 сравнений символов для x86, x64 и WOW64, а также проверки мёртвых клавиш.
- Аудиты пакетов проверяют хеши 18 ZIP-архивов, содержимое отдельных папок, копии README, локальные ссылки и кодировку. Реальный путь запуска установщика также проверен без записи в 32- и 64-разрядной PowerShell.
- Пользователь сообщает об успешной общей ручной проверке исправленного кандидата **Spanish (Spain) - Angle Quotes** в Windows Home x64, указанная версия 26H2, сборка 26300.9818. Отдельные случаи не записывались. Это не подтверждает ручную проверку остальных 16 раскладок или всех поддерживаемых версий Windows. Новые переводы не прошли независимую языковую проверку.

Дополнительная проверка совместимости со слов пользователя: при уже установленной раскладке v0.1.0 установщик v0.2.0 правильно распознал существующую установку и позволил выбрать её по умолчанию. Это подтверждает данный сценарий на проверенном компьютере, но не полное удаление и повторную установку или охват всех раскладок.

## Загрузки

Выберите `ANGLE_QUOTES_NATIVE_WINDOWS.zip` для всех раскладок или отдельный ZIP для своей. Полностью распакуйте ZIP и храните файлы вместе. В `SHA256SUMS.txt` приведены хеши SHA256 всех 18 загружаемых ZIP-архивов.

Архивы **Source code** ZIP/TAR.GZ на GitHub создаются отдельно и не являются пакетами установки.
