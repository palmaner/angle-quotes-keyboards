## Новый установщик

- Исправляет ошибку **1605**, связанную со смешением системной регистрации раскладки и установки MSI для текущей учётной записи.
- При удалении выбирается реально зарегистрированный продукт после проверки его MSI в кеше, имени и DLL, а не предполагается его совпадение с загруженным пакетом.
- Существующие установки для пользователя удаляются из учётной записи владельца. Установки для компьютера требуют разрешения администратора.
- Новые установки регистрируются для всего компьютера; раскладка по умолчанию остаётся отдельной настройкой каждой учётной записи.
- Отсутствующие, неоднозначные или непроверяемые продукты выявляются до восстановления настройки по умолчанию. Файлы раскладок и записи реестра не удаляются вручную.
- Окно и диалоги теперь показывают **v0.2.1**. В свойствах файла указана та же версия. Удаление системной раскладки может затронуть другие учётные записи.

## Надёжность и документация

- Новые установки MSI явно используют `ALLUSERS=1`. Удаление установки для пользователя не перезапускается от имени другого администратора.
- Подробные журналы `/L*V` и сведения о продукте и контексте сохраняются локально в `%LOCALAPPDATA%\AngleQuotes\logs`. Они не отправляются автоматически и могут содержать идентификаторы учётных записей и пути.
- Код успеха `0` сверяется со списком MSI до подтверждения завершения. Код необходимости перезагрузки `3010` сохраняется. Версия берётся из единого источника.

## Совместимость и предупреждения

DLL раскладок, пакеты MSI, назначения символов и тренировочные тексты не изменились по сравнению с v0.2.0. Сохраняется поддержка Windows 10/11 на x86/x64; ARM64 не включена. Для появления или правильной работы раскладки Windows может потребовать выход из системы или перезагрузку.

SmartScreen: предупреждение «Система Windows защитила ваш компьютер» с надписью «Неизвестный издатель» наблюдалось при запуске setup.exe, загруженного с GitHub, как в v0.1.0, так и в v0.2.0. Установщики по-прежнему не имеют цифровой подписи. Если вы проверили источник файла и решили продолжить, выберите «Подробнее», затем «Выполнить в любом случае», если Windows предлагает этот вариант. Отключать SmartScreen или Microsoft Defender не требуется.

## Проверки

- 26 изолированных проверок идентичности и контекста MSI и существующие 35 проверок настроек проходят в Windows PowerShell 5.1 для 32 и 64 бит. Настройки Windows и операции MSI имитируются.
- 238 проверок метаданных, архитектур, имён, встроенных ресурсов и версий охватывают все 17 раскладок. DLL и пакеты MSI не изменились.
- Проверяются хеши 18 ZIP-архивов, содержимое папок, копии документации, локальные ссылки и кодировка. Проверки без записи охватывают нативное обнаружение MSI и реальный запуск.
- Я успешно проверил Spanish (Spain) в новой учётной записи: установку, включение/отключение по умолчанию, сохранение после выхода из системы или перезагрузки и удаление. Сначала я удалил старую установку для пользователя. Я не проверял вручную другие 16 раскладок и все конфигурации Windows; переводы не прошли независимую языковую проверку. Финальная сборка добавляет отображение версии к проверенной логике.

Если старая установка принадлежит другой учётной записи, сначала удалите её из исходной учётной записи, затем установите эту версию из нужной. Создание новой учётной записи или запуск нового установщика не переносит существующую регистрацию MSI для пользователя. Я успешно выполнил этот переход, а затем повторил полную проверку в новой учётной записи.

## Загрузки

Выберите `ANGLE_QUOTES_NATIVE_WINDOWS.zip` для всех раскладок или отдельный ZIP для своей. Полностью распакуйте ZIP и храните файлы вместе. В `SHA256SUMS.txt` приведены хеши SHA256 всех 18 загружаемых ZIP-архивов.

Архивы **Source code** ZIP/TAR.GZ на GitHub создаются отдельно и не являются пакетами установки.
