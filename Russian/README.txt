Russian - Angle Quotes

Я создал эту раскладку, чтобы добавить угловые кавычки непосредственно в Windows, без AutoHotkey и фоновых приложений.

ИЗМЕНЁННЫЕ СОЧЕТАНИЯ (БЫЛО → СТАЛО)

AltGr+5: не назначено → «
AltGr+7: не назначено → »

Этим сочетаниям символы не были назначены; существующие символы не перенесены.

Windows 10/11 на ПК x86 или x64; ARM64 не включена. Интернет и установка Keyboard Layout Creator не нужны.

1. Полностью распакуйте ZIP и откройте папку нужной раскладки. Сохраните все файлы вместе.
2. Открывайте setup.exe обычным способом, без «Запуск от имени администратора». Флажок «Использовать по умолчанию для моей учётной записи» необязателен: установите его, чтобы сохранить настройку между сеансами. Права администратора запрашиваются только для установки.
3. Нажмите Win+Пробел и выберите название, оканчивающееся на “- Angle Quotes”.
4. Проверьте AltGr (правый Alt) и верхний ряд цифр в Блокноте.

Установщик иногда ведёт себя нестабильно: может потребоваться выйти из системы и войти снова, чтобы раскладка появилась или заработала.

Если setup.exe не запускается, откройте _amd64.msi для 64-разрядной Windows или _i386.msi для 32-разрядной. Установщики не подписаны; Windows может показывать неизвестного издателя. При прямом открытии MSI флажок раскладки по умолчанию недоступен.

Чтобы перестать использовать раскладку по умолчанию, снова откройте setup.exe, снимите флажок и нажмите «Применить». Прежняя настройка восстановится, а раскладка останется установленной. Если прежняя раскладка недоступна, выберите другую. Для удаления нажмите «Удалить» в том же окне; при необходимости сначала восстанавливается прежняя настройка. Win+Пробел переключает текущую раскладку, но не отменяет эту настройку. Прямое удаление через приложения Windows или MSI не выполняет это восстановление.

SmartScreen: предупреждение «Система Windows защитила ваш компьютер» наблюдалось в v0.1.0, но не при успешной проверке кандидата v0.2.0. Установщики v0.2.0 по-прежнему не имеют цифровой подписи и могут показывать это предупреждение. Эта версия не отключает и не удаляет защиту.
