# Feedback and contributions

I welcome reports from people testing the layouts on their own keyboards.

Please include:

- Your Windows version and the exact layout name.
- The keys you pressed, expected character and actual result.
- Whether the issue concerns installation, selection, typing or removal.
- Whether signing out and back in changed the result.

Check the local README first: some AltGr symbols are intentionally replaced. For the Swiss variants, ¢ and ¦ currently have no replacement shortcuts.

For a mapping change, explain the existing Windows behaviour and how displaced characters remain accessible. Update the relevant instructions and run the character-table and installer-name checks. Keep experimental variants clearly marked.
