# Practice texts

I generated these fictional texts with AI for typing practice. **They may contain linguistic, factual or punctuation errors.** They are exercises, not authoritative examples of each language's writing conventions.

Every paragraph includes at least one complete pair of angle quotes, used for speech, a written message or a brief quotation. The exercises alternate quoted passages with ordinary prose so that opening and closing quotes are practised in context rather than as isolated symbols.

Open a text below, copy the prose and paste it into **custom** mode on [Monkeytype](https://monkeytype.com/), or another typing tool that accepts custom text. Keep the text in its original order to practise complete sentences. Select the keyboard layout you want to test before starting.

The categories describe **the length of each paragraph**, not the size of the file or the length of the story. Short paragraphs are usually around **10–25 words**, medium paragraphs **25–50**, and long paragraphs **80–120**. Complete sentences and quotations are kept together, so a few paragraphs fall slightly outside these ranges. Blank lines separate paragraphs; the story may continue across them. Copy one paragraph, several or the whole collection. The combined file collects everything.
