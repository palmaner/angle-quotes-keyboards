Гэтым спалучэнням сімвалы не былі прызначаны; існыя сімвалы не перанесены.

Windows 10/11 на ПК x86 або x64; ARM64 не ўключана. Інтэрнэт і ўсталяванне Keyboard Layout Creator не патрэбныя.

1. Цалкам распакуйце ZIP і адкрыйце папку сваёй раскладкі. Захоўвайце файлы разам.
2. Адкрывайце setup.exe звычайным спосабам, без «Запуск ад імя адміністратара». Сцяжок «Выкарыстоўваць па змаўчанні для майго ўліковага запісу» неабавязковы: пазначце яго, каб захаваць наладу паміж сеансамі. Правы адміністратара запытваюцца толькі для ўсталявання.
3. Націсніце Win+Прабел і выберыце назву з заканчэннем “- Angle Quotes”.
4. Праверце AltGr (правы Alt) і верхні рад лічбаў у Нататніку.

Усталёўшчык часам паводзіць сябе нестабільна: можа спатрэбіцца выйсці з сістэмы і ўвайсці зноў, каб раскладка з’явілася або запрацавала.

Калі setup.exe не запускаецца, адкрыйце _amd64.msi для 64-бітнай Windows або _i386.msi для 32-бітнай. Усталёўшчыкі не падпісаны; Windows можа паказваць невядомага выдаўца. Пры прамым адкрыцці MSI сцяжок раскладкі па змаўчанні недаступны.

Каб перастаць выкарыстоўваць раскладку па змаўчанні, зноў адкрыйце setup.exe, зніміце сцяжок і націсніце «Ужыць». Папярэдняя налада адновіцца, а раскладка застанецца ўсталяванай. Калі папярэдняя раскладка недаступная, выберыце іншую. Для выдалення націсніце «Выдаліць» у тым жа акне; пры неабходнасці спачатку аднаўляецца папярэдняя налада. Win+Прабел пераключае бягучую раскладку, але не скасоўвае гэтую наладу. Прамое выдаленне праз праграмы Windows або MSI не выконвае гэтае аднаўленне.

SmartScreen: папярэджанне «Сістэма Windows абараніла ваш камп’ютар» назіралася ў v0.1.0, але не падчас паспяховай праверкі кандыдата v0.2.0. Усталёўшчыкі v0.2.0 па-ранейшаму не маюць лічбавага подпісу і могуць паказваць папярэджанне. Гэтая версія не адключае і не выдаляе абарону.
